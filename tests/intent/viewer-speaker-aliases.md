# Viewer speaker aliases — test intent

- A reviewed name follows the stable speaker ID across source passages and supported full-transcript speaker prefixes; another speaker and spoken mentions of the ID stay unchanged.
- Repeated name changes update the visible source immediately while the original transcript, source IDs, timestamps, and speaking fractions remain unchanged.
- A transcript search selection retains its original character offsets, exact spoken text, and whitespace after display substitution.
- Unknown or unsupported prefixes remain original source text. Empty rename requests keep the existing naming contract.
