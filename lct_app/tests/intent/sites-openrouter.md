# Hosted OpenRouter generation — test intent

- Exercise the Worker public API with every generated Drizzle migration applied to isolated in-memory SQLite and synthetic source/completion fixtures. Global fetch is intercepted; no live provider, key, identity, transcript, storage or database is used.
- Require explicit server model/provider/data-policy/audience/request/token settings, key, enable and budget-confirmation flags. Check the actual admission table before reporting ready; missing schema or configuration refuses without upstream traffic. Request/token caps do not prove a USD cap.
- Require exact-origin explicit OpenRouter processing consent and optional trusted identity only for configured authenticated audience. Bound and validate source before atomically reserving an attempt. Generated output is returned without saving or publishing it.
- Concurrent, interval and lifetime limits persist across policy changes; all reserved attempts remain counted on success, failure, timeout or cancellation. Unknown upstream completion retains the concurrency slot until owner investigation. Never automatically retry.
- Send one fixed HTTPS request with the server key, explicit model/provider allowlist, strict schema and no fallback; project out account/source identifiers, audio and source timestamps/speakers. Use actual portable reader/Discussion to verify returned source-linked artifacts.
- Sanitize provider/malformed/oversized/invalid-provenance failures. Bound stalled request and response bodies; propagate delivered abort signals and clean up readers/listeners/timers. Pre-admission cancellation makes no call. Real hosted disconnect propagation remains a later acceptance check because Cloudflare requires enable_request_signal; local tests do not prove that flag is present.
