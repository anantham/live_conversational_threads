# Workflow request ownership

- Switch prompts while a details or history request is unsettled. Only the selected prompt can supply editable content or history, including when an earlier request settles late.
- Reload prompts from file and read a new copy of the current selection. Show the template actually returned after reload.
- Verify recorder setup can use a healthy capability when the other check fails or stalls.
- Verify audio import exposes a retry after a stalled setup and ignores late responses. Cancelling before decode produces content allows departure while active and unsaved imports retain navigation protection.
