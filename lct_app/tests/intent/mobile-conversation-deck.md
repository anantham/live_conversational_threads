# Mobile conversation deck — test intent

- A compact touch viewer opens on one fixed, readable card at the highest authored tier instead of a scaled desktop graph.
- Horizontal gestures and controls move chronologically only among the current parent’s children; downward navigation drills into the selected branch and upward navigation restores its parent.
- Drilling past a moment reaches exact artifact utterances with speaker, timestamp, transcript text, and a permission-preserving recording link when available.
- Empty or incomplete hierarchy levels explain what is unavailable without trapping the reader, while every gesture has a keyboard/button equivalent and reduced-motion mode removes travel.
- Desktop continues to render the existing graph, header, legend, details, and timeline behavior unchanged.
