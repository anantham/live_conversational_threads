# Test intent: explicit local STT authority

- Automatic live and import routing selects approved M5 first, then approved
  Asus only when M5 is unavailable.
- Ordinary saved preferences and payload overrides cannot introduce cloud STT;
  local exhaustion is descriptive and terminal.
- A validated, session-scoped BYOK grant authorizes only its requested cloud
  provider and keeps large imports on the provider-aware path.
- Segmented, sequential, and delayed jobs cannot bypass the resolved authority;
  delayed state remains credential-free and re-resolves when executed.
