2026-10-02 06:43 IST. Status: bounded integration groundwork within the approved cloud migration. Hosted ChatGPT-plan inference eligibility, supported credentials and funding remain unconfirmed; no actual provider request is authorized by this bridge.

It does not export the explicit-edge version2 .threads contract, preserve recording provenance, or verify parent/child/source references. Wiring that legacy result directly into cloud storage would lose evidence and could save an unreadable or misleading map.

Add a separate pure createRecordingThreads bridge. It reuses the existing source normalizer, consumes generated nodes/metadata and explicit edges, checks identity/evidence/hierarchy/edge invariants, and returns the existing portable artifact plus a bounded local File. The source remains authoritative for utterances, words, speakers, timing and transcription completeness. Generated text is distinct from exact evidence. Structural linked-utterance coverage is distinct from semantic correctness or a completed argument relation scan.

No new provider, OAuth stack, model choice, paid fallback, secret/identity/retention policy, runtime activation, database or route is selected here. The service has no network/persistence side effects and is not yet mounted in the recording page. Future inference integration must use a supported approved credential route, explicit processing consent, observable cancellable stages and separate deliberate public/private saves; the full migration still requires a real generated-map journey.
